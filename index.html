gv

Консольный клиент GitVerse, устроенный по образцу gh. Репозитории, pull request'ы, задачи и релизы без ухода из терминала.

gv repo view
gv pr list --state all
gv issue create --title "Падает на старте" --body-file notes.md
gv api /user --jq .login

Установка

Через Go

Работает без токена и без дополнительных настроек:

go install gitverse.ru/veryviolet/gv/cmd/gv@latest

apt

GitVerse держит родной реестр deb-пакетов и сам подписывает метаданные, поэтому apt проверяет подпись обычным образом, без trusted=yes. Ключ отдаётся анонимно.

sudo mkdir -p /etc/apt/keyrings
sudo curl -fsSL https://gitverse.ru/api/packages/veryviolet/debian/repository.key -o /etc/apt/keyrings/gitverse-veryviolet.asc
echo 'deb [signed-by=/etc/apt/keyrings/gitverse-veryviolet.asc] https://gitverse.ru/api/packages/veryviolet/debian stable main' | sudo tee /etc/apt/sources.list.d/gitverse-veryviolet.list
sudo apt update && sudo apt install gitverse-cli

dnf

Файл .repo генерирует сам сервер, gpgcheck в нём включён.

sudo dnf config-manager --add-repo https://gitverse.ru/api/packages/veryviolet/rpm/gv.repo
sudo dnf install gitverse-cli

Пакет называется gitverse-cli, команда — gv. Имя gv в Debian и Ubuntu занято просмотрщиком PostScript (GNU gv), причём с epoch 1:, из-за которого его версия всегда старше нашей. Оба пакета владеют /usr/bin/gv, поэтому у нашего объявлен Conflicts: gv.

Пакеты файлом

Готовые deb, rpm и apk под amd64 и arm64 лежат в релизах. В пакет входят бинарник, man-страницы и автодополнения для bash, zsh и fish.

# Debian, Ubuntu, Astra
gunzip -c gitverse-cli_0.3.1-1_amd64.deb.gz > gv.deb && sudo dpkg -i gv.deb

# Fedora, RHEL, Alma, Rocky, РЕД ОС
gunzip -c gitverse-cli-0.3.1-1.x86_64.rpm.gz > gv.rpm && sudo rpm -i gv.rpm

# Alpine
sudo apk add --allow-untrusted gitverse-cli_0.3.1-r1_x86_64.apk

Авторизация

OAuth device flow у GitVerse нет, поэтому токен создаётся в веб-интерфейсе на странице настроек и вставляется в gv:

gv auth login

Токен хранится в ~/.config/gv/hosts.yml с правами 0600. Переменные GV_TOKEN и GITVERSE_TOKEN имеют приоритет над файлом и на диск не пишутся. Чтобы git ходил по HTTPS с тем же токеном — gv auth setup-git.

API GitVerse требует токен для всех эндпоинтов, включая чтение публичных репозиториев: анонимных запросов не бывает.

Машинный вывод

У всех списковых команд есть --json, --jq и --template. В терминале вывод табличный и цветной, в пайпе — TSV без цветов.

gv pr list --json --jq '.[] | "\(.number) \(.title)"'
gv repo list --template '{{range .}}{{tablerow .full_name .visibility}}{{end}}{{tablerender}}'

Чего нет

Это ограничения API платформы, а не пробелы клиента:

Аналог в ghПочему нет
gh pr mergeВ API есть только проверка «смержен ли»; эндпоинта на слияние нет
gh pr reviewReview-эндпоинтов в спецификации нет
gh search reposИз поиска доступен только поиск пользователей
gh labelМетки только читаются, CRUD нет
